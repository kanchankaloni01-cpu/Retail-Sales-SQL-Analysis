# Retail Sales Data Analysis using MySQL

## Project Overview 
Performed Exploratory Data Analysis (EDA) on a retail sales dataset containing 1,000 transaction records using MySQL to uncover category performance, monthly sales trends, and customer demographics.

## Key SQL techniques used 
- **Database & Schema Design: Created structured relational tables ('CREATE DATABASE', 'CREATE TABLE').
- **Aggregations & Filtering.**
'SUM()', 'COUNT()', AVG()', 'GROUP BY', and 'HAVING' to identify high-spending customers and top categories.
- **Time-Series Analysis:**
'DATE_FORMAT()' and 'YEAR()' to track monthly revenue and order volume.
- **Customer Segmentation:**
'CASE WHEN' conditional logic to categorise buyers into Young (<35) and Senior (35+)segments.
## Key Business Insights 
- **Gender Revenue;** Female customers generated $232,840 in total sales compared to $ 223,160 by Male customers.
- **Age Segmentation:** Senior customer (35+) accounted for 648 orders, while Young customers (<35) placed 352 orders.
